### What I take on

**Backend systems.** REST and GraphQL APIs in Node.js, TypeScript, NestJS, or Express. PostgreSQL with Prisma. Docker, queues, auth, payments. Designed for concurrency from the start — atomic transactions, idempotency, optimistic locking where the domain calls for it.

**Web3 & smart contracts.** Hedera (HTS, HCS, smart contracts), Solana programs, Solidity. Token launches, escrow, on-chain marketplaces, NFT mints.

**Full-stack delivery.** Next.js, React, and React Native (Expo) for projects where one person needs to own the whole stack end-to-end.

### Selected work

#### [`agbejo`](https://github.com/elshaddaioheha/agbejo) — Trustless P2P escrow on Hedera
Smart-contract escrow for peer transactions. Funds lock on-chain and only release on mutual confirmation — no platform-level trust required. TypeScript, React, Hedera.

#### [`talllie-reservation-api`](https://github.com/elshaddaioheha/talllie-reservation-api) — Concurrency-safe booking engine
A restaurant booking API designed around the failure case first: two users tapping *Reserve* on the same table at the same time. Atomic PostgreSQL transactions, a best-fit seating algorithm, no double-bookings under load.

#### [`ayan-collection`](https://github.com/elshaddaioheha/ayan-collection) — Programmatic NFT minting on Hedera
Built for the Hedera Africa Hackathon 2025. Node.js script that mints the Àyàn Collection on Hedera Testnet via the Hedera Token Service.

#### [`SwenAutos`](https://github.com/elshaddaioheha/SwenAutos) — Auto-parts marketplace
End-to-end TypeScript marketplace — listings, inventory, checkout — with clean separation between domain and transport layers.

#### [`node-template-oheha`](https://github.com/elshaddaioheha/node-template-oheha) — Opinionated Node.js starter
A strict take on Separation of Concerns: controllers stay thin, services stay pure. Includes a small validation DSL for payload schemas, Husky + Commitlint, and structured error handling out of the box.

#### [`text-analyzer-rs`](https://github.com/elshaddaioheha/text-analyzer-rs) — Rust CLI
Small text-analysis CLI written as a study in Rust's performance characteristics for CPU-bound work.
