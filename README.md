## 🏛️ System Design & Engineering Highlights

I focus on building production-ready systems that handle edge cases gracefully. *Pin these repositories to see the code.*

### 🔹 High-Concurrency Reservation Engine
*See `talllie-reservation-api`*
* **The Challenge:** Managing restaurant bookings without double-booking tables during high traffic.
* **The Solution:** Implemented **Interactive Transactions** and atomic operations in PostgreSQL to prevent race conditions.
* **The Logic:** Developed a **"Best-Fit" Algorithm** to optimize seating capacity dynamically.

### 🔹 Enterprise Node.js Architecture
*See `node-template-oheha`*
* **The Standard:** A strict implementation of **SoC (Separation of Concerns)** moving logic out of controllers and into pure services.
* **The Innovation:** Features a **Custom Validation DSL (VSL)**—a domain-specific language written to validate complex JSON payloads more strictly than standard libraries.
* **The Workflow:** Pre-configured with Husky, Commitlint, and localized error handling strategies.

### 🔹 Decentralized Trust Systems
*See `Agbejo`*
* **The Goal:** Removing the middleman in P2P transactions.
* **The Tech:** Smart Contracts for escrow services ensuring funds are only released upon mutual verification.
